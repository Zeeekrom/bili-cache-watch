项目说明

Bili Cache Watch 是一个本地运行的哔哩哔哩缓存管理工具，用来导入缓存视频、检查公开视频状态，并在视频异常时保留本地预览入口。

基本介绍

项目面向本地缓存整理场景：你可以手动添加 BV 号，也可以从模拟器、本地文件夹或 Windows MTP 手机路径读取 entry.json，集中管理缓存条目。

技术介绍

后端基于 Node.js、Express 和 SQLite，定时检查视频状态；导入模块解析缓存元数据，使用 ffmpeg 生成可预览的 MP4，并支持本地弹幕播放与标题翻译缓存。

使用方法

先运行 npm install 和 npm run dev，打开 localhost:3000；登录后添加 BV 号或导入缓存，再点击全部检查筛选异常视频，必要时使用预览或下载 MP4。

缓存导入

从安卓模拟器或本地缓存文件夹读取哔哩哔哩 entry.json 文件。

从真机导入前，请连接 USB 数据线，在手机上允许文件访问，并确认上方路径指向哔哩哔哩下载缓存文件夹。
